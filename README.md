# NAT-TEST 4Q

A Japanese N4 mock exam with vocabulary, grammar, and reading sections.

- 文字・語彙: 28 questions, 25 minutes
- 文法・読解: 29 questions, 55 minutes

The static site is published with GitHub Pages using the workflow in `.github/workflows/pages.yml`.

## Run locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
